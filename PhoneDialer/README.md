PhoneDialer
===========

Simple Java Swing phone dialer.

How to build
------------

1. Compile:

```
javac -d bin src/PhoneDialer.java
```

How to run
----------

1. Run the Swing app:

```
java -cp bin PhoneDialer
```

Notes
-----
- Requires a Java JDK (8+). On Linux, ensure an X server/GUI session is available to display the window.
